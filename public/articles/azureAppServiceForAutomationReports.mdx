### Stage 3: Prepare to Send Email

Set up email automation with the following SMTP configuration:

Download below zip file and open in vs code
![image](../../static/EmailGenerator.zip)
![image](https://github.com/bhargavmurari7/blog/blob/main/docs/Articles/Images/AzureAppService/Slide23.png?raw=true)
![image](https://github.com/bhargavmurari7/blog/blob/main/docs/Articles/Images/AzureAppService/Slide24.png?raw=true)
![image](https://github.com/bhargavmurari7/blog/blob/main/docs/Articles/Images/AzureAppService/Slide25.png?raw=true)
![image](https://github.com/bhargavmurari7/blog/blob/main/docs/Articles/Images/AzureAppService/Slide26.png?raw=true)
![image](https://github.com/bhargavmurari7/blog/blob/main/docs/Articles/Images/AzureAppService/Slide27.png?raw=true)
```bash
smtp-util --sender:email@yourDomain.com --toList:emailid1;emailid2 --subject:Automation_TestReport --htmlFile:C:\\Automation\\API\\src\\main\\java\\Utilities\\AllureReportGenerator\\emailReport.html --displayName:K_Fleet_Desktop Automation Results --attachments: C:\\Automation\\API\\src\\main\\java\\Utilities\\AllureReportGenerator\\emailReport.html --port:YOUR_SMTP_PORT --host:YOUR_SMTP_HOST --userID:YOUR_SMTP_USERNAME--password:YOUR_SMTP_PASSWORD
```
once we run above command we should see some success log like below
